# HTML, CSS and JavaScript practice projects

Small projects I built while learning front-end development, by following video tutorials and then experimenting with the code. Each folder opens by itself: just open its `index.html` in a browser.

| Project | What it practices |
|---|---|
| [`planets-menu`](planets-menu) | CSS hover effects: `::before` / `::after`, `transform`, `transition`, `attr()` |
| [`parallax-scrolling-site`](parallax-scrolling-site) | JavaScript scroll events (`window.onscroll`) moving layered images at different speeds |
| [`pepsi-landing-page`](pepsi-landing-page) | A responsive landing page: Flexbox, CSS animations (`@keyframes`), media queries, Font Awesome icons |
| [`countdown-timer`](countdown-timer) | JavaScript dates and `setInterval`: counting down to Dec 31, 2026 |
| [`responsive-form`](responsive-form) | CSS Flexbox: a form that wraps and resizes with `flex-wrap`, `flex-basis` and `flex-grow` |
| [`vue-counter`](vue-counter) | Vue 3 basics from a CDN: `data`, `methods`, `@click`, `v-if` versus `v-show` |
